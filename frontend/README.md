# MEYRO Futuristic Web Dashboard

**Status:** Phase 22 Scaffold  
**Tech Stack:** Next.js 14, React 18, TypeScript, TailwindCSS  
**Backend API:** FastAPI running at `http://localhost:8000`

---

## Core Futuristic Interface Components

1. **Personal Baseline Visualizer:** Displays real-time personal normal bands (activity, resting heart rate, sleep duration) contrasted against wide population distributions.
2. **Longitudinal Timeline:** Shows continuous multi-week physiological tracking with color-coded confidence and quality bands.
3. **Deviation Radar:** Real-time deviation magnitude (Low / Moderate / High) with breakdown of primary contributing physiological signals.
4. **Safety & Transparency Card:** Prominently communicates that observed deviations are empirical statistical patterns, not clinical diagnoses.

---

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the interface.
